# 가슴속 3천원 카테고리 아이콘 관리

가슴속 3천원 앱의 **카테고리 아이콘**과, 지도에 표시되는 **사장님 가게 핀** 이미지를 Figma에서 관리하는 플러그인입니다.

새 카테고리가 생길 때마다 핀 이미지 8장(기본·최근 활동·쿠폰·인증 × 선택 전/후)을 손으로 만들던 일을 버튼 한 번으로 대신합니다.

## 할 수 있는 것

- 카테고리 아이콘 보기, 새로 추가, 이미지 바꾸기, 이름 바꾸기
- 안 쓰는 아이콘 보관하기 (지우지 않고 숨겨두기, 언제든 복원)
- 아이콘으로 사장님 가게 핀 8장 자동으로 만들기

## 준비물

- Figma **데스크톱 앱** (웹 브라우저에서는 설치할 수 없어요)
- Design System 파일 **편집 권한** (보기 권한만 있으면 실행되지 않아요)

## 설치 (처음 한 번)

1. 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기
2. Figma 데스크톱 앱 메뉴 → **Plugins → Development → Import plugin from manifest…**
3. 압축 푼 폴더 안의 `manifest.json` 선택

새 버전이 나오면 다시 받아서 **같은 폴더에 덮어쓰면** 됩니다. 폴더 위치가 바뀌면 3번을 다시 해주세요.

## 사용법

Design System 파일을 열고 **Plugins → Development → 가슴속 3천원 — 카테고리 아이콘 관리**를 실행합니다.

### ChatGPT로 아이콘 이미지 만들기 (선택)

이미지가 아직 없을 때 써요.

1. **카테고리 아이콘** 탭에서 카테고리 이름(한글)과 설명을 적어요
2. **아이콘 모음 이미지 복사** → ChatGPT 입력창에 붙여넣기
3. 카테고리 사진을 이어서 첨부해요
4. **프롬프트 복사** → ChatGPT에 붙여넣고 보내기
5. 만들어진 이미지를 PNG로 저장한 뒤 아래 순서로 등록해요

### 새 카테고리 아이콘 추가

1. **카테고리 아이콘** 탭에서 **이미지 선택**
2. 등록 이름을 영문으로 입력 (예: `hodduck`) · 영문 소문자, 숫자, `_`만 쓸 수 있어요
3. 확인 항목이 모두 초록색이면 **추가**

이미지 조건: **PNG · 정사각형 · 72×72px 이상 · 배경 투명**

### 사장님 가게 핀 만들기

1. **mappin 생성** 탭에서 아이콘 선택
2. **mappin 만들기** → 핀 8장이 만들어지고 화면이 그쪽으로 이동해요

### 이미지 · 이름 바꾸기

아이콘 목록의 **이미지** 또는 **이름** 버튼을 누릅니다. 이미지를 바꾸면 그 아이콘의 핀도 자동으로 같이 바뀌어요.

### 보관 · 복원

**보관**은 아이콘을 지우지 않고 "사용 안 함"으로 표시합니다. 이미 이 아이콘을 쓰는 화면은 깨지지 않아요. 핀은 `archive` 영역으로 옮겨집니다. **복원**을 누르면 원래대로 돌아와요.

## 작업이 끝나면

Design System 라이브러리를 **게시(Publish)** 해야 다른 파일에 반영됩니다. 게시는 플러그인이 대신할 수 없어요.

## 주의

- `category`, `menu`, `mappin`, `archive` 프레임 이름을 바꾸지 마세요. 플러그인이 찾지 못해요.
- 아이콘 아래 이름표는 플러그인이 자동으로 다시 그려요. 직접 고치지 마세요.
- 실수했다면 Figma에서 **Cmd+Z**로 되돌릴 수 있어요.
- 여러 명이 동시에 플러그인을 쓰지 마세요.

코드를 고치려면 [DEVELOPMENT.md](DEVELOPMENT.md)를 보세요.
